# UX Review Log

Running log of findings from recurring UX passes. Each finding carries a
**Severity** (how much it hurts the caterer), an **Effort** guess, and a
**Status** (`proposed` → Chante decides → `fix agreed` / `fixed` /
`dismissed`). Newest review at the top. Fixes are only applied once agreed.
(Same format as the camp repo's `docs/ux-review-log.md`; its board-relevant
lessons — name things don't code them, previews before mutations, flag don't
hide — are baked into `design-system.md`.)
